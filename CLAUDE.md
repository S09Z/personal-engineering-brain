## Claude Code Project Context

This repository is a Markdown-first Personal Engineering Brain.

Primary goals:

- collect relevant technical and financial news
- summarize information
- deduplicate repeated stories
- organize information into Themes and Topics
- maintain evolving Topic notes
- create daily and weekly synthesis

Obsidian Markdown files are the source of truth.

## Before Working

Read:

- `AGENTS.md`
- `NEWS_REGISTRY.md`
- `INGESTION_RULES.md`
- `PROGRESS.md`

Then inspect relevant existing notes before creating new ones.

## Important

Do not create infrastructure merely because it may be useful later.

Prefer:

Markdown → Obsidian → simple scripts → Claude

before adding databases, RAG systems, orchestration frameworks, or custom services.

When processing news:

- preserve sources
- preserve dates
- distinguish facts from interpretation
- avoid duplicate permanent notes

When uncertain whether two stories represent the same event, surface the uncertainty instead of silently merging them.
