# Personal Engineering Brain

A Markdown-first, Obsidian-compatible personal knowledge system for collecting, summarizing, organizing, and synthesizing technical and financial news.

## Core flow

News → Summary → Topic → Theme → Living Knowledge → Daily/Weekly/Monthly Synthesis

## Primary areas

- Markets: NASDAQ, S&P 500, SET50
- Software Engineering
- AI Engineering
- Data Engineering
- Data Science
- MLOps
- LLM
- AI Research

## Recommended V1 stack

- Obsidian
- Markdown
- Git
- Claude / Claude Code
- Codex
- RSS + manual URLs + Web Clipper

Keep the system simple. Add automation only when a real bottleneck appears.
