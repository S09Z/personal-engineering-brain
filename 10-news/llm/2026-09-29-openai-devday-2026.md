# OpenAI DevDay 2026: GPT-6.1 Sol, Ultrafast tier, Agents API computer use, Dots agents

## Summary

- OpenAI DevDay 2026 (2026-09-29) made more than 20 announcements across ChatGPT, Codex, models and the API.
- Most relevant for engineering:
  - **GPT-6.1 Sol**: per OpenAI, near-Astra capability at one-fifth of Astra's standard token prices.
  - **Ultrafast**: a premium speed tier, up to 8× faster in Codex and up to 6× in the API.
  - **Agents API** gains computer use, plus Codex's multi-agent, tool search and context compaction features.
  - **Codex** can now also run in the cloud; the CLI was refreshed.
- Consumer and team products: always-on "Dots" agents, ChatGPT Space, Pages.

## Updates

- 2026-10-01: reviewed against OpenAI's official recap, which could not be fetched on 2026-09-30. Two earlier statements were corrected (see "Corrections"). Status set to `retained`.
- 2026-09-30: note created from Engadget and 9to5Mac live coverage.

## What Happened

From OpenAI's recap (official). Performance statements are OpenAI's claims.

Models and speed:

- **GPT-6.1 Sol**: upgrade to GPT-6 Sol, positioned for agentic coding, computer use and professional work. Available to all API users and to Plus, Pro, Business, Enterprise and Edu.
- **Ultrafast**: up to 8× faster token generation (300 tokens/s) in Codex, up to 6× in the API. GPT-6 Astra Ultrafast is available now in the API, and in Codex on Pro 500 and Enterprise. GPT-6.1 Sol Ultrafast is "coming soon".

Developer tools:

- **Agents API with computer use**: agents can operate software. The API also takes on Codex's multi-agent capabilities, tool search, tool calling and context compaction. OpenAI runs the infrastructure.
- **Bedrock Managed Agents**: built with Amazon; OpenAI agents that run entirely inside AWS.
- **Decisions API**: answers a fixed set of developer-defined questions with pre-defined answers, for classification and routing. Limited preview.
- **Codex in the cloud**: Codex can run on a computer, remotely from a phone, or in the cloud, with reusable development environments.
- **Codex CLI refresh**: voice input, a new `/agents` view, improved session resume and worktree handling.
- **Code Review** and **Codex Security Cloud**: review of diffs before feedback goes to GitHub or GitLab; scheduled repository security scans with prepared fixes.

Plugins and MCP:

- **Plugin extensions**: plugins can add sidebar entries, interactive panels and file viewers inside ChatGPT.
- **MCP Events**: support for the proposed MCP Events specification, so plugins can trigger automations when something happens in a connected app.

Products and plans:

- **Dots**: always-on agents. Available on Pro and Business Premium in eligible markets; beta for Enterprise, Edu and Healthcare when an admin enables it.
- **ChatGPT Space**, **Pages**, collaborative slides (coming weeks), teams and shared tasks.
- **Pro 500**: a new plan with 25× the Plus usage allowance and access to Ultrafast. Engadget reports the price as $500/month.
- **Sign in with ChatGPT**: use a ChatGPT plan's allowance in 16 partner tools.
- **Private Intelligence**: zero data retention with automated safety processing; a "Private Inference" preview is planned for the fall.

## Corrections

- **Codex is not cloud-only.** The first version of this note repeated Engadget's "runs fully on the cloud". OpenAI's recap describes the cloud as an added place to run Codex, alongside local and remote use.
- **Ultrafast and GPT-6.1 Sol.** Engadget tied 300 tokens/s to GPT-6.1 Sol. Per OpenAI, Ultrafast is live for GPT-6 Astra; the GPT-6.1 Sol version is not out yet.

## Why It Matters

- The Agents API now bundles computer use, multi-agent orchestration and context compaction as a managed service. That is a direct alternative to building those pieces yourself.
- GPT-6.1 Sol at one-fifth of Astra's price changes the cost comparison for coding-agent workloads. This is interpretation; no independent benchmarks were checked.
