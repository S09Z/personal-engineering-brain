# OpenAI DevDay 2026: Dots agents, GPT-6.1 Sol, Ultrafast tier, cloud Codex

## Summary

- OpenAI DevDay 2026 (San Francisco, 2026-09-29) made "20+" announcements.
- Most relevant for engineering:
  - GPT-6.1 Sol
  - the "Ultrafast" speed tier
  - Codex running fully in the cloud
  - a managed Agents API (details still unverified, see below)
- Consumer and agent products: always-on "Dots" agents and a "ChatGPT Space" collaboration hub.

## What Happened

Reported by Engadget and 9to5Mac on 2026-09-29, both covering the event live:

- **Dots:** always-on agents with their own computer and browser. Engadget says they are available to select users from 2026-09-29, with one Dot included for Pro and Business Premium. 9to5Mac reports they are powered by the Astra model.
- **GPT-6.1 Sol:** 9to5Mac reports near-Astra coding and computer-use performance at one-fifth of Astra's token price, with cached input at $0.10 / 1M tokens.
- **Ultrafast:** Engadget reports 300 tokens/s ("8x faster") for GPT-6.1 Sol.
- **Codex:** per Engadget, it now runs fully in the cloud, with no local machine required, and can discover plugins mid-conversation.
- **Pricing:** a new $500/month Pro tier.
- **Other:** OpenAI Private Intelligence (preview), Sign in with ChatGPT, ChatGPT Space.

## Unverified / Conflicting

- **Agents API:** a managed agent runtime with a hosted browser and MCP server support. It appears only in search-engine summaries of CNBC/Axios coverage. Neither article could be fetched (HTTP 403).
- **Ultrafast speedup:** a search summary says "up to 8x in Codex, 6x in API". Engadget says "8x" without that split.

## Why It Matters

- It moves OpenAI's direct competitor to Claude Code (Codex) toward cloud-only agents.
